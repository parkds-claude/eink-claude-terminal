# 2026-10-02 — X4 를 SUMI 한글 펌웨어로 원복

## 요약

사용자 요청으로 X4 를 TourBox 키맵 표시 펌웨어(x4-terminal 계열)에서
**SUMI 한글 펌웨어(v3 keyfix, 2026-07-30 재덤프본)** 로 되돌렸다.
정품(stock) 복원이 아니다 — 정품 백업 bin 은 구 기기(`/Users/mymacpro/`)에만
있고 이 맥미니에는 sha256 만 있어 불가.

## 수행 순서

1. 기기 확인 — `esptool flash-id`: ESP32-C3 rev v0.4, MAC `14:63:93:f3:b8:88`,
   16MB. 포트는 `/dev/cu.usbmodem1401` (`usbmodem31101` 은 StackChan 이므로 주의).
2. 원복 이미지 검증 — `~/xteink-ebook/backups/sumi-korean-v3-REDUMP-2026-07-30-full.bin`
   sha256 `f19e5d81…` 기록값과 일치.
3. **현재 펌웨어 선백업** — `read-flash 0x0 0x1000000` (207초)
   → `backups/x4-tourbox-terminal-2026-10-02-full.bin`
   (sha256 `1ad3c4ab…`, 매직바이트 `e9`). bin 은 gitignore 대상이라 이 맥미니에만 있다.
   NVS 에 WiFi 자격증명·토큰이 들어 있으므로 외부 공유 금지.
4. 플래시 — `write-flash --flash-mode keep --flash-freq keep --flash-size keep 0x0 <이미지>`
   (71.5초), `Hash of data verified`.
5. 브리지 중지 — `launchctl bootout` + `launchctl disable gui/501/com.x4mirror.bridge`.
   plist 파일은 그대로 둠.

## 검증

- esptool 기록 후 해시 검증 통과.
- `x4-terminal.local` / `192.168.0.103` 의 `/status` 무응답 (구 펌웨어 내려감).
- USB 는 계속 열거됨.
- **화면 부팅 상태는 육안 미확인** — SUMI 홈 화면이 뜨는지 사용자 확인 필요.

## 영향 / 롤백

- TourBox 키맵 표시·터미널 미러 기능 정지. `bridge/`, `scripts/` 코드는 무수정.
- TourBox 표시로 되돌리려면:
  1. `esptool --chip esp32c3 --port /dev/cu.usbmodemXXXX write-flash --flash-mode keep --flash-freq keep --flash-size keep 0x0 backups/x4-tourbox-terminal-2026-10-02-full.bin`
  2. `launchctl enable gui/501/com.x4mirror.bridge`
  3. `launchctl bootstrap gui/501 ~/Library/LaunchAgents/com.x4mirror.bridge.plist`
