1. **X4 USB 인식 문제 해결**: BOOT 홀드 재연결로 `/dev/cu.usbmodem101` 인식 (MAC `14:63:93:f3:b8:88` — 기존 기기 동일 확인)
2. **긴급 백업**: SUMI v3 펌웨어 16MB 전체 덤프 → `~/xteink-ebook/backups/sumi-korean-v3-REDUMP-2026-07-30-full.bin` (sha256 `f19e5d81…`, 매직바이트 검증). 구 백업 bin은 구 기기(`/Users/mymacpro/`)에만 존재 — 이 덤프가 유일한 원복 수단
3. **플래시**: xteink-terminal 펌웨어 (bootloader 0x0 / partitions 0x8000 / boot_app0 0xe000 / app 0x10000), 해시 검증 통과
4. **Wi-Fi 프로비저닝 (무접촉)**: 맥미니 en1을 `X4-Terminal-Setup` AP에 붙여 WiFiManager 포털(192.168.4.1)에서 X4측 스캔 확인 → `/wifisave`로 iptime_ss 주입 (비밀번호는 사용자 제공 — 키체인 추출은 권한 차단)
5. **보안 강화 (자체 패치)**: `/frame`·`/reset-wifi`에 **X-Auth 토큰 인증** 추가
   - 펌웨어: `FRAME_TOKEN` 빌드플래그 + `collectHeaders` + 401 처리 (`main.cpp`)
   - 브리지: `--token` 인자 추가 (`x4_tmux_bridge.py`)
   - 토큰: `~/eink-claude-terminal/.x4-token` (chmod 600, gitignore)
   - 검증: 무토큰 POST → **401**, 토큰 POST → **204** ✅
   - 앱 파티션(0x10000)만 재플래시해 NVS(Wi-Fi 자격증명) 보존 → 재부팅 후 자동 재접속 확인
6. **미러 가동**: `scripts/start_mirror.sh` (표준 진입점) — tmux 세션 생성 + 브리지 nohup 기동 (pid/log 파일 관리)
7. **왕복 검증**: `tmux send-keys` → Claude Code 입력창 반영 → lastFrameMs 증가로 X4 전송 확인

## (추가 2) 폰트 확정 + 저전력 + 안정화

- **폰트 최종: 24px (66×17셀)** — 사용자가 28px 테스트 패턴 크기 선호 → 28px 시도 → "너무 크다" → 24px 확정. `start_mirror.sh` 기본값.
- **저전력 문의 답**: e-ink는 정지 시 전력 0, 흑/백 반전은 절전 무관(잔상만 늘어남) → 흰 바탕 유지. 실질 개선 = **Wi-Fi 모뎀 슬립** (`WiFi.setSleep(true)`, 대기 ~100mA→~20mA). 적용 후 RTT 33ms로 지연 무해.
- **첫 OTA 무선 플래시 성공** (espota, 케이블 불필요 확인).
- **브리지 안정화 2건**: ① 5분 주기 위생 전체갱신(`--full-every 300`) ② X4 재부팅 자동 감지(15초마다 /status 확인, 비트맵 모드 아니면 전체 프레임 재전송) — OTA/전원 재시작 후 화면 멈춤 문제 해소.
- 진단 노하우: 화면 이상 문의 시 캘리브레이션 패턴(테두리+대각선+눈금)으로 하드웨어/콘텐츠 문제를 분리 판정. "세로 절반" 증상 = Claude Code 웰컴 화면 레이아웃 + 잔상이었음 (하드웨어 정상).
