## 물리버튼 페이지업/다운 (Phase 2-②)

- 조사: X4 버튼은 GPIO1/2 ADC 저항 래더 (freeink-sdk InputManager 실측값 차용)
  - GPIO2: Up(~2242)/Down(~5), 무입력 >3900 / GPIO1: Back·Confirm·Left·Right
- 펌웨어: pollButtons() 10ms 폴링 + 30ms 디바운스 + 600ms 홀드 시 250ms 자동반복,
  카운터를 GET /btn("up,down")과 /status(btnUp/btnDown)로 노출. OTA 플래시 완료 (커밋 61f3252)
- 브리지: /btn을 기존 0.12s 루프에서 폴링 → 증분만큼 스크롤 오프셋 이동,
  tmux capture-pane -S/-E 히스토리 캡처(세션 비침투), 우상단 ^Np 반전 배지,
  최대 스크롤 = history_size/rows 클램프, 90초 방치 시 라이브 자동복귀,
  스크롤백에서는 커서 미표시
- 남은 것: 실기 버튼 매핑 확인 (하단 버튼이 Up/Down 래더인지 Left/Right인지 —
  눌러보면 /btn 카운터로 판별 가능)
