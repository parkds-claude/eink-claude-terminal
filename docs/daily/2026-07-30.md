## 발견한 블로커 2건

### ⚠ 블로커 1: X4가 USB 시리얼로 안 잡힘
- 사용자가 "맥미니-X4 연결됨"이라 했으나 `/dev/cu.usbmodem*` 미검출, `system_profiler`에도 없음
- 추정 원인: 충전 전용 케이블 / 기기 전원 꺼짐 / 허브 문제
- ESP32-C3의 USB-Serial/JTAG는 하드웨어 내장이라 정상이라면 켜져만 있어도 잡혀야 함
- **확인 필요**: 데이터 지원 케이블로 직결 + 기기 전원 ON 후 `ls /dev/cu.usbmodem*`

### ⚠ 블로커 2: 펌웨어 백업 원본(.bin)이 이 맥미니에 없음
- `~/xteink-ebook/backups/`에 **sha256 해시 파일만** 있고 실제 bin 없음
- 해시 파일 내 경로가 `/Users/mymacpro/...` — 구 기기에서 미이관
- **플래시 전 반드시 현재 펌웨어(SUMI v3) 전체 덤프 필수**:
  ```sh
  esptool --chip esp32c3 --port /dev/cu.usbmodemXXXX read-flash 0x0 0x1000000 \
    ~/xteink-ebook/backups/sumi-korean-v3-keyfix-REDUMP-2026-07-30.bin
  ```
  덤프 후 sha256이 기존 해시(`21ce6f0f…`)와 일치하는지 검증
