# 2026-08-12 — X4 역할 전환: 터미널 미러 → TourBox 키맵 표시

## 요약

TourBox Elite(오늘 USB 연결·Console 5.11.3 설치)의 키 세팅을 X4 e-ink 에
실시간 표시하는 기능을 구축하고, 기존 터미널 미러를 대체했다.
사용자 요구: ① 키 세팅 변경 실시간 반영 ② 앱별 프리셋(PPT·일러 지정,
그외 일반) ③ 깔끔한 다이어그램 표기 ④ 리버스엔지니어링 근거 확보
⑤ 자체검증 후 커밋·푸시.

## 구현

- `bridge/tourbox/` 신규 패키지 (읽기 전용, Console 디렉터리 파싱)
  - `codes.py` — 슬롯/키코드/수정키 상수. 단일 17종은 tourbox-preset(MIT)
    캘리브레이션, 콤보 27종은 presetConf items 배열로 자체 도출
  - `store.py` — tourbox.db configBytes(30테이블×3350B) + ShortDesc 조인
  - `watch.py` — tourbox.log tail (앱/프리셋 전환 실시간, inode/truncate 내성)
  - `render.py` — 800×480 스펙 다이어그램(기기 스키매틱+콜아웃) + 콤보
    목록 페이지 + 프리셋 없음 화면
  - `selftest.py` — 26 테스트 (디코드·렌더·워처·라이브 불변식)
- `bridge/x4_tourbox_display.py` — 표시 데몬. 전송 계층(post_band 등)은
  x4_bitmap_bridge 재사용. X4 버튼: 위/아래=메인↔콤보, 확인=전체 리프레시
- `scripts/mirror_daemon.sh` — X4_MODE 도입(기본 tourbox, mirror 롤백 가능).
  launchd plist(com.x4mirror.bridge)는 무수정
- `scripts/start_tourbox_display.sh` — 수동 기동 진입점

## 리버스엔지니어링

상세: [docs/tourbox-format.md](../tourbox-format.md). 핵심 발견:
- configBytes = 30 프리셋 테이블, 레코드 13B = [슬롯코드][type,aux,A(5),B(5)]
- ShortDesc `<s>` = SWT 키코드 (확장키 = 0x1000000|코드) → payload 와 조인
- presetConf category items 배열 = Console UI 슬롯 나열 = 슬롯 코드 → 콤보
  슬롯 도출, 공식 Illustrator 프리셋 의미(SIDE더블=Undo, TOP+▲=Rectangle,
  SIDE+TALL=Cut)로 교차 검증
- 참고 리포: YongHee-Kim/tourbox-preset (MIT)

## 검증

- 단위+라이브 테스트 26/26 통과 (`python3 -m tourbox.selftest`)
- 3개 프리셋(Photoshop/Illustrator/PowerPoint-EN) 렌더 눈검증 —
  공식 프리셋 의미와 라벨 정합 확인
- 워처 시뮬레이션: 전환/부분줄/truncate 모두 통과
- 데몬 드라이런: X4 미접속 백오프·설정 리로드 정상
- launchd 전환 완료, 신규 데몬 가동 중 (X4 전원 오프 상태 — 켜지면 자동 push)

## 주의/롤백

- 미러로 되돌리기: launchd 환경에 `X4_MODE=mirror` 지정 또는
  `X4_MODE=mirror scripts/mirror_daemon.sh`
- tmux 세션 x4-terminal 은 삭제하지 않음 (미러 롤백 대비)
- X4 실기 표시 확인은 기기 전원 인가 후 필요 (2026-08-12 18:04 현재 오프라인)
