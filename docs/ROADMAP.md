## 결정 기록

### D1. 1호기 = Xteink X4 (베어 패널·Core Ink 아님)
- **이유**: 보유 e-ink 중 최대·최고해상도(4.3" 480×800) + 부분갱신 + 배터리·케이스 완제품 + 플래시/복구 절차와 정품 백업이 이미 확보됨. Core Ink(200×200)는 터미널로는 25×12자 수준이라 탈락, 베어 패널은 케이스·배터리 없음.
- **비용**: 현재 X4의 SUMI 한글 워드프로세서 펌웨어를 지우고 터미널 펌웨어를 올림 → 이북/워드프로세서 기능 일시 상실.
- **탈출구**: `~/xteink-ebook/backups/`의 정품 백업 + SUMI 머지 이미지로 언제든 원복. 예비기 X3도 보유.

### D2. Phase 1 방식 = xteink-terminal 미러 (네이티브 SSH 아님)
- **이유**: SSH 스택·터미널 에뮬레이터를 ESP32-C3(RAM 380KB)에 얹는 대신 맥미니가 tmux 화면을 캡처해 밀어주는 구조 — 난이도가 한 자릿수 낮고, 기성 레포(maddiedreese/xteink-terminal)가 존재.
- **비용**: X4 단독으로는 동작 불가(맥미니 필수). 초기엔 출력 전용(입력은 키보드→맥미니 직결).
- **탈출구**: 불만족 시 Phase 3(네이티브)로 승격하거나 보험 트랙(Pi+PaperTTY)으로 전환.

### D3. 외부 사용 = Cloudflare Tunnel + 기기 비밀키 (Tailscale 직결 아님)
- **이유**: ESP32는 Tailscale 클라이언트가 될 수 없음. cardputer-relay(buddy.prefloor.io, x-device-secret 헤더)에서 이미 검증된 패턴 재활용.
- **비용**: 터널 도메인 1개 추가, 브리지에 인증 코드 필요. 폴링 방식이라 완전 실시간은 아님(1~2초 주기 — e-ink 특성상 체감 무해).
- **탈출구**: 터널 제거하면 집 전용(Phase 1 상태)으로 즉시 회귀.

### D4. Cardputer SSH 검증(외부 제안 ①안)은 생략
- **이유**: 보유 기기는 Cardputer-**Adv**로, 커뮤니티 SSH 레포들(원판 대상)과 키보드 하드웨어(GPIO 매트릭스 vs I2C 컨트롤러)가 달라 "반나절 검증"이 성립 안 함. 개념은 이미 커뮤니티에서 증명됨.
- **비용**: 없음 (기존 Adv 앱 보존).
- **탈출구**: Adv용 키보드 드라이버를 얹은 포크가 나오면 재검토.

### D5. Pi Zero 2 W + PaperTTY(외부 제안 ②안)는 "보험"으로 보류
- **이유**: 유일한 추가구매 트랙(~5만원, Pi + Waveshare 4.2" HAT). mosh·리눅스 폰트·BT 페어링이 공짜로 해결되는 가장 확실한 길이지만, 보유 기기로 먼저 시도하는 것이 프로젝트 취지.
- **비용**: 보류 자체는 0원. 전환 시 ~5만원 + 배송 대기.
- **탈출구**: Phase 1~2가 e-ink 반응성 기대에 못 미치면 즉시 발주.
